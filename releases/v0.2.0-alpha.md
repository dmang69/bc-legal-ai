# BC Legal AI Associate — v0.2.0-alpha

**Release date:** 2026-07-28  
**Git tag:** `v0.2.0-alpha`  
**Classification:** Prototype / Internal Alpha foundation (**not** production)

## What this release is

A supervised BC tenancy / JR **workbench** with:

- Canonical FastAPI platform API (`backend/`)
- Matter isolation, auth sessions, hash-chained audit (SQLite default)
- Counsel skills packs under `skills/`
- Deterministic public static demo (`huggingface-space-static/`)
- Fail-closed design locks (Form 66, ATA s.57, consent ≠ privilege, etc.)

## What it is not

- Not a lawyer, not legal advice, not court-ready export certification  
- Not multi-worker production Postgres/OCR/official-law retrieval  
- Not safe for real-client confidential data on public surfaces  

## Highlights since v0.1 remediation

### Monorepo cleanup
- Non-canonical trees moved to `archive/non-canonical/`:

### P0 security (alpha)
- Bearer auth required on legacy HITL / post-resolution routes  
- **Matter ACL** enforced on those routes (`require_matter_access`)  
- Cross-org denial tests  
- Deny-first **ethical wall** tests (blocks owner/admin)  
- In-process **login/register rate limits** (env-tunable; Redis still required for multi-host)  
- Baseline **security headers** (CSP, X-Frame-Options, nosniff, Referrer-Policy)

### Quality gates (local)
- Full pytest suite green  
- Confidential-data scan green  
- Public-demo deployment readiness green  

## Run locally

```bash
pip install -r requirements.txt
# PowerShell: $env:APP_MODE="development"
export APP_MODE=development
uvicorn backend.api.main:app --reload --port 8000
```

API docs: http://127.0.0.1:8000/docs  

## Rate-limit env knobs

| Variable | Default | Meaning |
|----------|---------|---------|
| `ALA_RATE_LIMIT_LOGIN` | 20 | Login attempts per window per IP+email |
| `ALA_RATE_LIMIT_LOGIN_WINDOW` | 60 | Window seconds |
| `ALA_RATE_LIMIT_REGISTER` | 10 | Register attempts per window |
| `ALA_RATE_LIMIT_REGISTER_WINDOW` | 60 | Window seconds |
| `ALA_RATE_LIMIT_DISABLED` | (unset) | Set `1` to disable (tests only) |
