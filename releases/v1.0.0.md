# BC Legal AI Associate — v1.0.0

**Release date:** 2026-07-28  
**Classification:** Production-ready **infrastructure** for supervised / synthetic operation  

## What “1.0.0” means

This tag marks a **stable, deployable foundation**: builds, tests, Docker, env docs, auth, health probes, CI gates, and an enterprise AI suite behind fail-closed legal controls.

It does **not** certify:

- unsupervised legal advice or representation  
- real-client public multi-tenant SaaS without org security/legal review  
- court-ready automated filing  

## Highlights

- FastAPI modular monolith + platform-ui chat shell  
- Auth: register/login/logout, bearer + HttpOnly cookies + CSRF  
- Postgres multi-worker path + portable migrations  
- Enterprise AI suite (Ollama, tools, arena) with org quotas  
- Form 66 scaffold, BC Laws fetch, OCR path, court package gates  
- CI: lint, SQLite tests, Postgres tests, frontend build, Docker smoke, production_smoke  

## Install (quick)

```bash
pip install -e ".[dev,export,pdf]"
cp .env.example .env
uvicorn backend.api.main:app --port 8000
# optional UI
cd apps/platform-ui && npm ci && npm run dev
```
